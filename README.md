# Hotel Casa Theo

Sitio web estático para un hotel boutique en Arequipa, desarrollado con Astro, TypeScript y Tailwind CSS.

## Comandos

```sh
pnpm install
pnpm dev
pnpm build
```

La página prioriza HTML semántico, imágenes responsivas generadas por Astro, accesibilidad y una carga mínima de JavaScript.
